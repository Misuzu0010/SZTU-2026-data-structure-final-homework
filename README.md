# 星环算力平台调度

这个仓库分享我在「星环算力平台调度」中的凹分结果，供学习和迭代参考。题目需要在不知道后续事件的情况下做调度，单组时限只有 1 秒，提交次数也有限。这里不是标准答案，也不保证最优；公开目前的最高分版本，是希望大家不用从零试起，少花一些时间和 token。

## 从哪里开始

| 文件 | 用途 |
| --- | --- |
| [题面](星环算力平台调度.md) | 查看交互协议、计费规则和数据范围。 |
| [阅读版源码](StarRing_阅读版.cpp) | 带中文注释，建议从这份代码开始修改。 |
| [提交版源码](StarRing.cpp) | 压缩后的 ASCII 单文件，当前为 16,304 字节。 |
| [第六版源码分析](StarRing/docs/第六轮策略总结.md) | 顺着代码了解对账、工作流排序、机架和机器选择。 |
| [第六轮迭代记录](StarRing/docs/第六轮迭代记录.md) | 查看改动、对照实验和未采用的方案。 |

建议先在阅读版上迭代，验证后再打包。如果提交失败，可以先检查源码是否为 ASCII、是否保留 LF 换行，以及文件是否**严格小于 16,384 字节**；提交失败不一定是文件过长。

## 成绩与交流

我目前记录的最高成绩是 **81/100**。据说可以用 Claude系列模型做到 90 分以上。

有更高分迭代结果的同学可以提 PR。如果方便，附上策略改动和同一批用例上的利润、耗时对比，方便大家复现。
